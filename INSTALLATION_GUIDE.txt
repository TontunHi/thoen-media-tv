========================================================================
            คู่มือและขั้นตอนการติดตั้งระบบ THOEN MEDIA TV
                 (Digital Signage Management System)
========================================================================

ระบบจัดการสื่อประชาสัมพันธ์และป้ายดิจิทัล (Digital Signage) พัฒนาด้วย:
- Next.js (App Router) + React
- Prisma ORM + Better-SQLite3
- Tailwind CSS v4
- PM2 สำหรับการรัน Service เบื้องหลัง (Production)

------------------------------------------------------------------------
[ 1. ความต้องการของระบบ (Prerequisites) ]
------------------------------------------------------------------------
1. Node.js: แนะนำเวอร์ชัน 20.x หรือ 22.x LTS ขึ้นไป
   - ดาวน์โหลดได้ที่: https://nodejs.org/
   - ตรวจสอบเวอร์ชันโดยรันคำสั่ง:
     node -v
     npm -v

2. Git: สำหรับดาวน์โหลดและจัดการเวอร์ชันโค้ด
   - ดาวน์โหลดได้ที่: https://git-scm.com/

3. OS: ใช้งานได้ทั้ง Windows, Linux (Ubuntu/Debian) และ macOS

------------------------------------------------------------------------
[ 2. ขั้นตอนการติดตั้งจาก GitHub (Installation Steps) ]
------------------------------------------------------------------------

ขั้นตอนที่ 1: โคลนโปรเจกต์จาก GitHub
--------------------------------------------------
เปิด Terminal / Command Prompt / PowerShell แล้วพิมพ์:

  git clone https://github.com/TontunHi/thoen-media-tv.git
  cd thoen-media-tv


ขั้นตอนที่ 2: ติดตั้ง Dependencies (Node Modules)
--------------------------------------------------
รันคำสั่ง:

  npm install

* หมายเหตุ: ในขั้นตอนนี้ระบบจะรันสคริปต์ postinstall เพื่อทำการเตรียม
  SQLite Prebuild และสั่ง prisma generate ให้อัตโนมัติ


ขั้นตอนที่ 3: ตั้งค่า Environment Variables (.env)
--------------------------------------------------
สร้างไฟล์ .env จากไฟล์ต้นแบบ .env.example:

  - บน Windows (PowerShell):
    Copy-Item .env.example .env

  - บน Linux / macOS / Bash:
    cp .env.example .env

ตรวจสอบ/แก้ไขค่าในไฟล์ .env ตามต้องการ:
--------------------------------------------------
DATABASE_URL="file:./data/signage.db"
JWT_SECRET="เปลี่ยน_KEY_ความปลอดภัยตรงนี้_ให้เป็นค่าสุ่มยาวๆ"
NEXT_PUBLIC_APP_NAME="Thoen Media TV"
--------------------------------------------------


ขั้นตอนที่ 4: สร้างฐานข้อมูลและบัญชี Admin เริ่มต้น (Database Setup)
--------------------------------------------------
1. รันการอัปเดต Schema ไปยังฐานข้อมูล SQLite:
   npx prisma db push

2. ทำการเพิ่มข้อมูลเริ่มต้น (Initial Admin & Default Playlist):
   npx tsx prisma/seed.ts

   * ข้อมูลล็อกอินเริ่มต้น:
     - Username: admin
     - Password: admin123
     (แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังเข้าสู่ระบบครั้งแรก)


------------------------------------------------------------------------
[ 3. วิธีการรันโปรเจกต์ (Running the Project) ]
------------------------------------------------------------------------

แบบที่ 1: สำหรับ Development (โหมดพัฒนาและทดสอบ)
--------------------------------------------------
  npm run dev

- เข้าใช้งานผ่านเบราว์เซอร์:
  - เมนูหลัก / หน้าจอควบคุม: http://localhost:3000
  - หน้าต่างแสดงผลสำหรับจอทีวี: http://localhost:3000/tv/[screen-slug]


แบบที่ 2: สำหรับ Production (โหมดใช้งานจริง)
--------------------------------------------------
1. ทำการ Build โปรเจกต์:
   npm run build

2. รัน Service:
   npm start

   หรือใช้ PM2 เพื่อให้ระบบทำงานตลอดเวลาและ Restart อัตโนมัติเมื่อเปิดเครื่อง:
   npm install -g pm2
   pm2 start ecosystem.config.js
   pm2 save
   pm2 startup


------------------------------------------------------------------------
[ 4. โครงสร้างโฟลเดอร์สำคัญ ]
------------------------------------------------------------------------
- /app                 : โค้ดหน้าเว็บ Next.js และ API endpoints
- /app/(admin)         : หน้า Dashboard และจัดการสื่อ/จอแสดงผล
- /app/tv/[slug]       : หน้า Player สำหรับเปิดแสดงผลบนจอทีวีแบบเต็มจอ
- /data                : โฟลเดอร์เก็บฐานข้อมูล SQLite และไฟล์สื่อ (Uploads/Thumbnails)
- /prisma              : Schema ของฐานข้อมูล และสคริปต์ Seeding
- /components          : คอมโพเนนต์ UI ต่างๆ
- /lib                 : ฟังก์ชัน Utility, การเชื่อมต่อ Prisma Client และ Auth

------------------------------------------------------------------------
[ 5. การแก้ไขปัญหาเบื้องต้น (Troubleshooting) ]
------------------------------------------------------------------------
Q: ติดปัญหาเรื่อง better-sqlite3 build error บน Windows/Linux?
A: ให้รันคำสั่ง:
   npm run postinstall
   หรือ
   npx prisma generate

Q: ลืมรหัสผ่าน Admin?
A: สามารถรันสคริปต์ reset ข้อมูลเริ่มต้นใหม่ได้โดย:
   npx tsx prisma/seed.ts
